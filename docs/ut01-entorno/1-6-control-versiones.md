# 1.6 Control de versiones

## Control de versiones

Durante el curso se utilizarán repositorios *Git* tanto para la entrega de prácticas como para facilitaros el disponer de un repositorio con control de versiones.

Para instalar *Git*:

- en GNU/*Linux* *Ubuntu*:

```bash
sudo apt-get update
sudo apt-get install git
```

- en *Microsoft* *Windows*: instalación basada en "siguientes"   [aquí](https://git-for-windows.github.io/)*.*

Para usar *Git* en *Visual Studio Code* se recomienda repasar las guías contenidas [aquí](https://code.visualstudio.com/docs/editor/versioncontrol) y **sobre todo** [aquí](http://www.mclibre.org/consultar/informatica/lecciones/vsc-git-repositorio.html).
[Aquí](https://code.visualstudio.com/docs/introvideos/versioncontrol) un ejemplo del uso de *Git* dentro de *Visual Studio Code.*
