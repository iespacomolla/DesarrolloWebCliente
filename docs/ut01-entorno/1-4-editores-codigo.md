# 1.4 Editores de código (entornos de desarrollo)

## Editores de código (entornos de desarrollo)

Existen diversos entornos de desarrollo, desde los más sencillos (*Brackets*, *Notepad++*, *Sublime o* *Visual Studio Code*) a interfaces más complejas como *Aptana* o *Eclipse*. En este manual se usará ***Visual Studio Code***. Es muy potente y posee un gran ecosistema de *plugins* para ampliar su funcionalidad.

Aquí algunos manuales libres de uso para aprender más sobre ***Visual Studio Code*** en castellano: para su instalación [aquí](http://www.mclibre.org/consultar/informatica/lecciones/vsc-instalacion.html) y para su personalización [aquí](http://www.mclibre.org/consultar/informatica/lecciones/vsc-personalizacion.html).
