# 1.5 Editores online

## Editores online

Para hacer pequeñas pruebas el hecho de tener que crear un documento HTML que enlace a un documento *JavaScript* se puede hacer tedioso. Para ello existen diferentes "parques" donde jugar con código. Dos de los más conocidos son ***JSBin*** ([http://jsbin.com](http://jsbin.com/)) y ***JSFiddle*** ([http://jsfiddle.net](http://jsfiddle.net/)).

Ambos permiten probar código en caliente e interactuar con `HTML`, `CSS` y usar bibliotecas de terceros como *jQuery*. Es una buena alternativa a un editor pero para probar pequeñas porciones de código.
