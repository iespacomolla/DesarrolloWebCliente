# 1.2 Manual de referencia

## Manual de referencia

Elemento imprescindible a la hora de aprender un lenguaje es su
referencia. Para ello, *Mozilla* mantiene la MDN (*Mozilla Developer Network*) con una extensa referencia de *JavaScript* llena de ejemplos, [aquí](https://developer.mozilla.org/en/docs/Web/JavaScript/Reference) que también está traducida (aunque en muchas ocasiones sin tanto contenido) [aquí](https://developer.mozilla.org/es/docs/JavaScript/Referencia). A lo largo del manual se hará referencia estos contenidos para ampliar la información.
