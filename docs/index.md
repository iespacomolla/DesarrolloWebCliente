## Resultados de Aprendizaje (Real Decreto)

1. **RA1.** Selecciona las arquitecturas y tecnologías de programación sobre clientes web, identificando y analizando las capacidades y características de cada una.
2. **RA2.** Escribe sentencias simples, aplicando la sintaxis del lenguaje y verificando su ejecución sobre navegadores web.
3. **RA3.** Escribe código, identificando y aplicando las funcionalidades aportadas por los objetos predefinidos del lenguaje.
4. **RA4.** Programa código para clientes web analizando y utilizando estructuras definidas por el usuario.
5. **RA5.** Desarrolla aplicaciones web interactivas integrando mecanismos de manejo de eventos.
6. **RA6.** Desarrolla aplicaciones web analizando y aplicando las características del modelo de objetos del documento.
7. **RA7.** Desarrolla aplicaciones web dinámicas, reconociendo y aplicando mecanismos de comunicación asíncrona entre cliente y servidor.
