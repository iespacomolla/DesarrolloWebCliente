# 2.8 Estructuras de control

## Estructuras de control

En programación, una estructura de control es un bloque de código que dicta el flujo de ejecución de un programa. Básicamente, son las reglas que le dicen a la computadora qué camino tomar, qué decisiones hacer y cuándo repetir una acción.

Si un programa no tuviera estructuras de control, simplemente ejecutaría las instrucciones línea por línea, de arriba a abajo, de forma rígida. Gracias a ellas, tu código puede reaccionar a diferentes situaciones, evaluar datos y automatizar tareas repetitivas.
