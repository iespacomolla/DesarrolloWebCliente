# 7.1 Trabajando con objetos

Los **objetos** en *JavaScript* son colecciones de claves mutables o inmutables como *arrays*, funciones (*Function*), los números (*Number*), las cadenas de texto (*String*), las fechas (*Date*), las expresiones regulares (*RegExp*) y los objetos (*Object*). Para crear un objeto se puede utilizar en constructor *new* aunque se pueden crear de diferentes formas:

```javascript
var obj = new Object();
var str = new String();
var cadena = “Esto también es un objeto string”;
```
